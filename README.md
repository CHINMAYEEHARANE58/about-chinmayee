# About Chinmayee

A visual portfolio inspired by the scroll-led composition of [About Sen](https://about.senbuzy.com/). The character was created from Chinmayee's supplied photo. The page uses original code and new artwork; it does not include the reference site's character, stickers, résumé, or project media.

## Run locally

```sh
python3 -m http.server 5173
```

Open `http://localhost:5173`.

## Personalize

Update the biography, timeline, work cards, and contact section in `index.html`. Replace `assets/chinmayee-character.png` if you want to revise the character. The page is static HTML, CSS, and JavaScript, so it does not need a build step.
